รายงาน (#10) · mock-up

ข้อมูลตัวอย่าง: ต.ค. 2026, ทุกกระเป๋า, THB. ภาพ 1 คือข้อเสนอหลัก (Q1-B). กรอบเส้นประทอง E1 = ส่วนเสริมที่เลือกได้. ตัวเลขทุกตัวคำนวณบนเครื่องจาก local DB ไม่มี API ใหม่.

สิ่งที่ต้องตัดสิน (รายละเอียดใน docs/features/report.md → Open questions)

  • Q1 กราฟตามหมวด: A โดนัท · B แถบแบ่งสัดส่วน + รายการเรียงมากไปน้อยมีแถบ (เสนอ) · C รายการอย่างเดียว. วาด SVG เอง ไม่ใช้ lib
  • Q2 ช่วงเวลา: เดือน (ค่าเริ่ม) / ไตรมาส / ปี / กำหนดเอง ผ่าน ⋮ "ดูตาม" + chip แบบแท็บธุรกรรม; แนวโน้ม 6 เดือน / 4 ไตรมาส / 5 ปี
  • Q3 กระเป๋า: ตัวสลับเดิม ใช้กระเป๋าที่เลือกร่วมกับแท็บธุรกรรม (ช่วงเวลาแยกกัน)
  • Q4 เงินที่บันทึกลงหมวดหลักโดยตรง: แถว "ไม่ระบุหมวดย่อย" ใต้หมวดหลัก
  • Q5 เจาะลง: หน้าในแท็บ (‹ กลับ) ไม่ใช่ชีต · แถวธุรกรรมเปิดชีตแก้ไขเดิม
  • Q6 หลายสกุลเงิน: chip เลือกสกุลเงิน โผล่เมื่อมี >1 สกุลเท่านั้น (ภาพ 8)
  • E1–E5 ส่วนเสริม: ยอดต้น/ปลายงวด · เทียบงวดก่อน · เฉลี่ยต่อวัน · ยอดงวดก่อนของหมวด · บรรทัด "ไม่รวมในรายงาน"
