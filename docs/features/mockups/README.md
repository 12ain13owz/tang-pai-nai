# Mock-ups

Each file here is a **snapshot of a design decision**: the screens the owner chose from while
a feature was being decided (option names like H1 / S3, frame numbers). The feature docs and
`ROADMAP.md` refer to those names, which is why the files stay.

- **Don't update them** when the app changes. They show what was on the table at the time,
  not how the app looks now.
- Where a mock-up and the app disagree, the feature's doc (`docs/features/<feature>.md`) and
  [`web/DESIGN.md`](../../../web/DESIGN.md) are right.
- A new mock-up for a feature that already has one is a new file (`sharing-16.2.html`), never
  an edit of the old one.
