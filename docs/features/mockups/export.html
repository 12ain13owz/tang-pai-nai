ส่งออก CSV และย้ายรายการไปหมวดอื่น (#15)

Mock-up ธีม Midnight Gold (dark) จอ 375 px · ตัดหน้าค้นหาและตัวกรองออกแล้ว (เจ้าของสั่ง) · ส่งออกอยู่ที่ บัญชี › ข้อมูลของฉัน · ย้ายรายการอยู่ในหน้าแก้หมวด

  • ไม่มีการเปลี่ยน API: การส่งออกอ่านฐานข้อมูลในเครื่อง ส่วนการย้ายรายการเป็น upsert รายแถว (บวกการแก้ hiddenCategoryIds ของกระเป๋าถ้าเลือกซ่อน) ใน local write เดียวผ่าน outbox
  • เครื่องที่ไม่ได้ตั้งเป็น trusted: ส่งออกได้ตามปกติ (อ่านอย่างเดียว) ส่วนการย้ายต้อง online และต่อ server ได้ เหมือนการแก้อื่น ๆ
  • ตัดออก (เจ้าของสั่ง): หน้าค้นหา ตัวกรองในแท็บธุรกรรมและรายงาน ตัวกรองอีเวนต์ (event.md Q10) และโหมดติ๊กทีละแถว
