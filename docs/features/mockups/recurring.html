รายการซ้ำ (#12) · mock-up รอบ 1

วันนี้ = อา. 8 พ.ย. 2026, โปรไฟล์ "ครอบครัว", THB. ภาพทั้งหมดเป็นข้อเสนอ (ข้อเสนอ ก ในคำถาม): เครื่องเขียนรายการที่ถึงกำหนดเองตอนเปิดแอป, กฎแต่ละอันเลือกได้ว่า "บันทึกให้อัตโนมัติ" หรือ "ถามก่อนบันทึก". เส้นประ/จาง = รายการที่ยังไม่ได้บันทึก (คาดการณ์จากกฎ ไม่นับในยอด).

สรุปภาพ

  • 1–4 ตั้งรายการซ้ำจากฟอร์มธุรกรรม: แถว "ทำซ้ำ" ใต้ "เพิ่มเติม" → view ในชีตเดียวกัน → บันทึกครั้งเดียวได้ทั้งกฎและรายการงวดแรก (ถ้าวันเริ่ม ≤ วันนี้)
  • 5–7 รายการกฎทั้งหมด (บัญชีผู้ใช้ › รายการซ้ำ และเมนู ⋮) + แก้กฎในชีต (หยุดชั่วคราว / ลบ ที่หัวชีต) + กฎที่กระเป๋าถูกเก็บถาวร
  • 8–11 ถึงกำหนด / กำลังจะมา: toast หลังบันทึกอัตโนมัติ, การ์ด "ถึงกำหนด" รอยืนยัน, ชีตยืนยัน/ข้าม, แท็บ "อนาคต"
  • 12 เปิดรายการที่สร้างจากกฎ: บรรทัด "จากรายการซ้ำ" ใต้ "เพิ่มเติม" ลิงก์ไปที่กฎ
