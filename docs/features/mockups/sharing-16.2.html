แชร์กระเป๋า 16.2 (#16) · editor เขียนลงกระเป๋าที่แชร์ · mock-up

วันนี้ = จ. 9 พ.ย. 2026. เจ้าของ = "พ่อ" (กระเป๋า "ค่าบ้าน") · สมาชิก editor = "แม่". editor เพิ่มได้แม้ออฟไลน์ (เข้า outbox อย่างเดียว ไม่ลงฐานข้อมูลเครื่อง) · แก้/ลบต้องออนไลน์ (ส่งทันทีพร้อม baseSeq) · รายการที่สมาชิกเพิ่ม: userId = เจ้าของ + addedBy = สมาชิก → "เพิ่มโดย …" · เจ้าของชนะเสมอ · viewer ไม่เปลี่ยนจาก 16.1.

สรุปภาพ

  • 1 editor: หน้ากระเป๋าที่แชร์ มีปุ่ม เพิ่มรายการ, แถว รอ sync แทรกในวันของมัน (ยังไม่นับในยอด/สรุป), "เพิ่มโดย …" ใต้แถว
  • 2 ชีตเพิ่ม (โหมดแชร์): กระเป๋าล็อก, หมวดของเจ้าของ, จำนวน/วันที่/โน้ต/ไม่นับในรายงาน; ไม่มีอีเวนต์ ทำซ้ำ โอน
  • 3 แตะแถว → ชีตแก้: บันทึก / ลบ (ส่งทันที ไม่ผ่าน outbox)
  • 4 ออฟไลน์: เพิ่มได้ (รอ sync), แตะแถวเปิดดูได้แต่แก้/ลบปิด
  • 5 แก้ชน (เจ้าของเพิ่งแก้แถวนั้น): toast + โหลดใหม่
  • 6 แท็บ sync ของ editor: ถูกเอาออกขณะมีรายการค้าง → บันทึกไม่สำเร็จ (ทิ้งได้อย่างเดียว); เจ้าของชนะทีหลัง → "ถูกแก้ไขโดย พ่อ"
  • 7 เจ้าของ: แท็บธุรกรรมแสดง "เพิ่มโดย แม่" (ชื่อจากรายชื่อสมาชิก, ออฟไลน์ = "สมาชิก")
